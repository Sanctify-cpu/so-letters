📜 RÈGLES DU JEU

🔤 LES LETTRES MANQUANTES

Un mot français est affiché avec certaines lettres remplacées par des underscores. Retrouvez le mot complet. La première lettre est toujours cachée !

🧩 LES DEVINETTES

On vous donne : la première lettre, le nombre de lettres, et une définition. Trouvez le mot exact !

🏆 LE MOT GAGNANT

Des lettres mélangées sont présentées. Réorganisez-les pour former le mot correct. Chaque lettre doit être utilisée une seule fois.

💃 LA DANSE DES MOTS

Une phrase est découpée en mots mélangés. Reconstituez la phrase exacte dans l'ordre correct.
